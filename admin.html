🔑One-time setup: publishing key

The website is stored on GitHub. To let this page update it, make a GitHub key once and paste it here. It's saved only in this browser on this device. Anyone can open this page, but only someone with the key can change the website.

  1. Open GitHub → new fine-grained token (signed in as ).
  2. Token name: Dorm Points. Expiration: pick a long one, like 1 year (you'll make a new key when it runs out).
  3. Repository access: choose Only select repositories, then pick .
  4. Permissions: add Contents and set it to Read and write.
  5. Click Generate token, copy it, and paste it below.
No key? Update by hand instead

Click Download points.json above, then on GitHub open the data folder of the repository, choose Add file → Upload files, drop the file in and click Commit changes. The website updates about a minute later.
